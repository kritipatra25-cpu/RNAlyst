# Gene Identity Reconciliation Report: OSD-120 RNA-Seq Analysis

## 1. Reconciliation Summary

This document presents a read-only scientific reconciliation of gene identities for the 8 candidate genes identified in the OSD-120 RNA-seq primary analysis pipeline. 

### Key Findings
1. **TAIR10 Identifier Validity**: All 8 candidate gene identifiers (`AT1G01010`, `AT2G04170`, `AT3G17609`, `AT3G46640`, `AT4G04720`, `AT5G07390`, `AT5G13930`, `AT5G57630`) are **100% valid TAIR10 locus identifiers** corresponding to annotated genomic loci in *Arabidopsis thaliana*.
2. **Phase 1 Data Integrity**: All 8 gene IDs are present in the Phase 1 primary analysis output dataset (`results/osd120_primary_analysis/differential_expression.csv`). Phase 1 data integrity, raw counts, DESeq2 statistics, and file hashes remain completely intact and immutable.
3. **Root Cause of "Symbol = Unassigned"**:
   - The primary Phase 1 output file `differential_expression.csv` generated by DESeq2 stores columns `['gene_id', 'baseMean', 'log2FoldChange', 'lfcSE', 'stat', 'pvalue', 'shrunk_log2FoldChange', 'padj']` without inline gene symbol annotations.
   - When downstream summary tables and schemas rendered candidate reports directly from the primary DE CSV, missing annotation joins caused gene symbols to default to `"Unassigned"`.
   - Cross-referencing against reference annotation datasets (`data/reference_de_glds120.csv`) reveals that **7 of the 8 genes have standard Arabidopsis gene symbols** (e.g., `HYH`, `LUX`, `CPK21`, `RBOHA`, `CHS`, `CIPK21`, `ANAC001`).
   - 1 gene (`AT2G04170`) has no symbol entry in reference data and is explicitly reconciled as **"VALID TAIR ID — NO SYMBOL AVAILABLE"**.
